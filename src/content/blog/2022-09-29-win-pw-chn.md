윈도우 원격 데스크톱으로 접속했을 때 `Ctrl + Alt + Del`을 누르면 원격 PC가 아니라 현재 사용 중인 로컬 PC의 보안 옵션이 열립니다.

원격 데스크톱 환경에서 원격 PC의 보안 옵션을 띄우려면 **`Ctrl + Alt + End`** 키를 사용하면 됩니다.

만약 단축키가 먹지 않거나 원격 작업 중 바로 비밀번호 변경 창을 열어야 한다면, **`Win + R`** 실행 창에서 아래 명령어를 입력해 실행할 수 있습니다.

```text
C:\Windows\explorer.exe shell:::{2559a1f2-21d7-11d4-bdaf-00c04f60b9f0}
```

윈도우 보안 옵션 애플리케이션을 직접 호출하는 경로이므로, 바탕화면 등에 바로가기로 만들어 두면 필요할 때 편하게 사용할 수 있습니다.
